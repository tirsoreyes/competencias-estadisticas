# 3. Tendencia central

## Media

La media aritmética se obtiene sumando los valores y dividiendo entre el
número de observaciones.

`Media = suma de valores / número de valores`

Ejemplo:

Ventas:

1000, 1500, 2000

`Media = (1000 + 1500 + 2000)/3`

`Media = 1500`

------------------------------------------------------------------------

# 4. Mediana

Es el valor central cuando los datos están ordenados.

Ejemplo:

1000, 1500, 2000

Mediana = 1500.

Con cantidad par:

1000, 1500, 2000, 2500

La mediana es el promedio de los dos valores centrales:

`(1500+2000)/2 = 1750`

------------------------------------------------------------------------

# 5. Moda

Es el valor o categoría que aparece con mayor frecuencia.

Ejemplo:

Contado, Tarjeta, Tarjeta, Transferencia, Tarjeta

Moda = Tarjeta.

------------------------------------------------------------------------

# 6. ¿Cuándo utilizar cada una?

### Media

Útil cuando queremos un promedio general y los datos no tienen valores
extremos que distorsionen demasiado el resultado.

### Mediana

Útil cuando existen valores extremos.

Ejemplo:

Ingresos:

8,000; 9,000; 10,000; 11,000; 100,000

La media queda fuertemente afectada por \$100,000.

### Moda

Muy útil con categorías.

Ejemplo:

Forma de pago más utilizada.

------------------------------------------------------------------------

# 7. Dispersión

La tendencia central no cuenta toda la historia.

Dos grupos pueden tener la misma media pero comportamientos muy
diferentes.

------------------------------------------------------------------------

# 8. Rango

`Rango = máximo - mínimo`

Ejemplo:

Ventas:

1000, 1500, 2000, 3000

`Rango = 3000 - 1000 = 2000`

------------------------------------------------------------------------

# 9. Varianza

Mide cuánto se alejan los datos respecto de la media, utilizando las
desviaciones al cuadrado.

Para esta materia no es necesario demostrar la fórmula.

Explicar:

> Una varianza mayor significa mayor dispersión de los datos.

------------------------------------------------------------------------

# 10. Desviación estándar

Es una medida de dispersión expresada en las mismas unidades de la
variable.

Ejemplo:

Si analizamos ventas en pesos, la desviación estándar puede expresarse
en pesos.

Interpretación sencilla:

-   desviación pequeña → datos relativamente cercanos;
-   desviación grande → datos más dispersos.

------------------------------------------------------------------------

# 11. Coeficiente de variación

Fórmula:

`CV = desviación estándar / media × 100`

Permite comparar variabilidad relativa entre conjuntos que pueden tener
escalas diferentes.

No profundizar más de lo necesario.

------------------------------------------------------------------------

# 12. Frecuencia

La frecuencia indica cuántas veces aparece un valor o categoría.

### Frecuencia absoluta

Número de observaciones.

### Frecuencia relativa

Proporción o porcentaje.

### Frecuencia acumulada

Suma progresiva de las frecuencias.

------------------------------------------------------------------------

# 13. Ejemplo

Forma de pago de 20 clientes:

-   Efectivo = 5
-   Tarjeta = 9
-   Transferencia = 6

Total = 20.

Frecuencia relativa de tarjeta:

`9/20 = 0.45 = 45%`

------------------------------------------------------------------------

# 14. Intervalos de clase

Cuando tenemos muchos valores numéricos distintos, podemos agruparlos.

Ejemplo de ventas:

  Intervalo      Frecuencia
  ------------ ------------
  0--999                  4
  1000--1999              8
  2000--2999              6
  3000--3999              2

Explicar que el agrupamiento facilita visualizar la distribución.

# 15. Tablas

Una tabla debe:

-   tener título;
-   identificar variables;
-   mostrar unidades cuando corresponda;
-   ser fácil de leer;
-   no contener información innecesaria.

# 19. Interpretación

No aceptar como respuesta:

> "La media es \$2,350."

Pedir:

> "La venta promedio de la muestra fue de \$2,350."

Después:

> "¿Qué significa eso para el negocio?"

La estadística debe terminar en una interpretación.
