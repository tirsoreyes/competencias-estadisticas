# 5. Dato

Un dato es un valor observado o registrado.

Ejemplos:

-   \$5,000 de venta;
-   25 años;
-   8 empleados;
-   "Contado";
-   15 días;
-   4 sucursales.

Un dato aislado puede tener poco significado. Su utilidad aumenta cuando
sabemos qué representa y en qué contexto fue obtenido.

------------------------------------------------------------------------

# 6. Unidad de análisis

Es la unidad sobre la cual se recopila información.

Ejemplos:

-   un cliente;
-   una factura;
-   un empleado;
-   una empresa;
-   una transacción.

### Ejemplo

Si estudiamos las ventas de una empresa por factura:

**Unidad de análisis = factura.**

------------------------------------------------------------------------

# 7. Población

Es el conjunto total que queremos estudiar.

Ejemplo:

Una empresa emitió 5,000 facturas durante el año.

Si queremos estudiar esas facturas:

**Población = 5,000 facturas.**

------------------------------------------------------------------------

# 8. Muestra

Es un subconjunto de la población.

Si estudiamos 500 de las 5,000 facturas:

**Muestra = 500 facturas.**

Explicar:

> La muestra debe seleccionarse de manera adecuada. No basta con escoger
> cualquier grupo de datos.

------------------------------------------------------------------------

# 9. Medición

Es el proceso mediante el cual asignamos valores o categorías a una
característica que queremos estudiar.

Ejemplos:

-   importe de venta → pesos;
-   edad → años;
-   satisfacción → escala;
-   forma de pago → categoría.

------------------------------------------------------------------------

# 10. Estadística descriptiva

Su función es organizar, resumir y presentar datos.

Ejemplos:

-   promedio de ventas;
-   venta mínima;
-   venta máxima;
-   tabla de frecuencias;
-   gráfica de ventas.

Pregunta:

> Si tenemos las ventas de enero y queremos resumirlas, ¿estamos
> describiendo o prediciendo?

Respuesta: **describiendo**.

------------------------------------------------------------------------

# 11. Estadística inferencial

Busca utilizar información de una muestra para obtener conclusiones
sobre una población.

Ejemplo:

Una empresa tiene 10,000 clientes. Analizamos una muestra de 500 y
utilizamos los resultados para inferir características de los 10,000.

Explicar que la inferencia implica incertidumbre y que por eso deben
utilizarse métodos estadísticos apropiados.

------------------------------------------------------------------------

# 12. Variables

Una variable es una característica que puede tomar diferentes valores.

Ejemplos:

-   edad;
-   ingreso;
-   ventas;
-   número de empleados;
-   método de pago;
-   satisfacción.

------------------------------------------------------------------------

# 13. Clases de variables

Para esta materia utilizar una clasificación sencilla.

## Cualitativa

Describe categorías.

Ejemplos:

-   sexo;
-   estado civil;
-   forma de pago;
-   tipo de cliente.

## Cuantitativa

Representa cantidades numéricas.

Ejemplos:

-   ventas;
-   edad;
-   ingreso;
-   número de productos.

### Cuantitativa discreta

Generalmente representa conteos.

Ejemplo:

Número de empleados = 25.

### Cuantitativa continua

Puede tomar valores dentro de un intervalo.

Ejemplo:

Importe de una venta = \$1,250.50.

------------------------------------------------------------------------

# 14. Proceso de investigación

Explicar de manera sencilla:

1.  Identificar un problema.
2.  Formular una pregunta.
3.  Definir qué información se necesita.
4.  Identificar población.
5.  Seleccionar muestra si es necesario.
6.  Recopilar datos.
7.  Organizar datos.
8.  Analizar.
9.  Interpretar.
10. Comunicar resultados.

La estadística puede intervenir en varias etapas.

# 15. Construcción de base de datos

## Concepto

Una base de datos estadística organizada puede representarse como:

-   **filas = unidades de análisis**
-   **columnas = variables**

Ejemplo:

  ID     Edad   Venta FormaPago   Sucursal
  ---- ------ ------- ----------- ----------
  1        25    1500 Tarjeta     A
  2        31    2300 Efectivo    B
  3        42    1800 Tarjeta     A

Cada fila representa una observación.

------------------------------------------------------------------------

# 16. Práctica en Excel

Crear un archivo llamado:

`competencias_estadisticas_clase1.xlsx`

Crear una hoja llamada:

`Ventas`

Columnas:

-   ID
-   EdadCliente
-   ImporteVenta
-   FormaPago
-   Sucursal
-   Productos
-   DiasCredito

Capturar al menos 20 registros ficticios.

### Reglas

1.  No dejar filas vacías entre registros.
2.  Una variable por columna.
3.  No mezclar texto y números en una misma variable.
4.  Utilizar nombres de columnas claros.
5.  Mantener el mismo formato en toda la columna.

# 18. Introducción a SPSS

### ¿Qué es?

IBM SPSS Statistics es un software estadístico utilizado para organizar
y analizar datos, realizar pruebas estadísticas y generar resultados.

El programa oficial contempla explícitamente su utilización.
fileciteturn1file0L27-L31

### Importante para el profesor

SPSS **no es gratuito de forma permanente**. IBM ofrece actualmente una
**prueba gratuita de 14 días**, y existen licencias académicas para
estudiantes y docentes. citeturn0search0turn0search6

Por lo tanto, **no debemos basar el curso en que todos los alumnos
tendrán SPSS**.

La estrategia será:

**Excel como herramienta garantizada + SPSS como herramienta
complementaria cuando esté disponible.**

### Instalación opcional

Si quieres utilizar la prueba:

urlPágina oficial de recursos y prueba de IBM SPSS
Statisticsturn0search0

IBM indica que la prueba requiere crear un IBMid, conexión a Internet y
funciona en Windows y macOS de 64 bits. citeturn0search0

Pasos:

1.  Entrar a la página oficial de IBM.
2.  Crear una cuenta IBMid.
3.  Iniciar la prueba.
4.  Descargar el instalador.
5.  Instalar.
6.  Iniciar SPSS.
7.  Ingresar con el IBMid.
8.  Verificar que abra correctamente.

**No exigir al alumno que pague SPSS.**
